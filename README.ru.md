# family-health

[English](README.md) | **Русский**

Self-hosted семейный дашборд здоровья с [Claude Code](https://docs.anthropic.com/en/docs/claude-code) в роли локального ассистента. Одна папка на семью: анализы, диагнозы, выписки, снимки. Данные лежат в JSON и обычных папках на диске — никакого облака, никакой БД. Работает под твоей подпиской Claude Code (OAuth через CLI), API-ключи не нужны.

![Дашборд](docs/screenshots/dashboard.png)

Интерфейс в стиле Apple Health (тёмная/светлая тема, русский). Кинь PDF в браузер — агент разложит по категориям, вытащит анализы, обновит диагнозы и покажет виджет-отчёт в чате.

## Возможности

- **Список семьи** — карточка на каждого члена слева, кнопка «Добавить». У каждого своя папка с `labs.json`, `diagnoses.json`, `metrics.json`, `documents.json` и подпапками (`Анализы`, `Заключения`, `Выписки`, `Снимки`, `_inbox`).
- **Дашборд** — активные диагнозы, последние анализы, сгруппированные по каноническим панелям (ОАК, биохимия, липидный профиль, гормоны, витамины…), тренды метрик (вес, глюкоза, давление), документы с drag-and-drop.
- **Чат по своим данным** — правая колонка. Агент читает папку активного члена, отвечает на вопросы по анализам, генерирует отчёты, разбирает загруженные документы. Виджеты стримятся как `SummaryCard`, `TrendChartCard`, `ReportCard`.
- **Только структурированный вывод** — общение с браузером идёт исключительно через MCP-сервер `health-ui` (`emit_message`, `emit_widget`, `add_lab_results`, `save_diagnosis`, `file_document`, `update_member_json`, `run_finished`). Терминал Claude не парсится.
- **Переиспользуемая сессия** — один tmux `health` с `claude` живёт фоном, каждое сообщение — `send-keys` в этот REPL. Никакого холодного старта на запрос.
- **Всё локально** — данные в `data/`. Наружу летят только LLM-вызовы Claude Code под твоей подпиской.

## Архитектура

```
Браузер ──POST /api/chat──▶ Next.js ──tmux send-keys──▶ [tmux «health»: claude REPL]
                                                            │  MCP tools (health-ui)
                                                            ▼
Браузер ◀──SSE /api/events── Next.js ◀──POST /api/ingest── health-ui MCP server

web/                Next.js 15 (App Router) + React 19 + Tailwind + recharts
  src/app/api/        chat, ingest, events (SSE), upload, members, auth
  src/components/     Sidebar, Dashboard, ChatPanel, widgets/, LabGroup, ...
  src/lib/tmux.ts     обёртка send-keys над tmux-сессией «health»
mcp/                MCP-сервер health-ui (stdio, TypeScript через tsx)
  src/index.ts        те самые семь инструментов
runtime/            start-claude.sh: idempotent boot tmux-сессии
data.example/       скелет для копирования в data/ при первом запуске
```

Личные данные (`data/`) и env (`web/.env.local`) под `.gitignore` — см. `data.example/` как шаблон.

## Как работать с чатом

Чат — основной способ общения с агентом. Всё, что пишешь, идёт в Claude с префиксом `[conv:<id>][run:<id>][member:<memberId>]` — так агент всегда знает, чью папку читать.

**Что можно спрашивать.** Про анализы (`«объясни ферритин 12, это норма?»`, `«когда последний раз сдавали ТТГ?»`), тренды (`«покажи вес за последний год»`, `«как менялось давление?»`), диагнозы (`«что у меня из активного?»`, `«когда пересдать глюкозу?»`), полный отчёт (`«собери отчёт по последнему визиту к терапевту»`).

**Как приходят ответы.** Агент стримит события в правильном порядке:
- текстовые сообщения (`emit_message`) с поддержкой Markdown;
- виджеты (`emit_widget`) — `SummaryCard` для тезисного summary, `TrendChartCard` для графика тренда, `ReportCard` для многосекционного отчёта;
- изменения данных (`add_lab_results`, `save_diagnosis`, `file_document`, `update_member_json`) — дашборд подхватывает их сам, в центре сразу появляются новые анализы/диагнозы.

Ход заканчивается вызовом `run_finished`, после чего разблокируется поле ввода.

**Загрузка документов.** Перетащи PDF/JPG в область документов (или на всю страницу) — файл окажется в `data/<memberId>/_inbox/`. Скажи `«разбери входящие»` — агент прочитает каждый файл, вытащит анализы/диагнозы, перенесёт в правильную категорию (`Анализы` / `Заключения` / `Выписки` / `Снимки`), обновит JSON и покажет виджеты с результатом. Если файл не распознаётся как медицинский (скриншот, фото) — уедет в `_media/` и останется не тронутым.

**История.** Каждый диалог сохраняется в `data/<memberId>/chat.json` — обновил страницу, продолжил. У каждого члена свой поток; переключаешь его в сайдбаре — переключается транскрипт. Удалил сообщение в UI — оно исчезнет из файла.

**Переключение члена семьи.** Активный `memberId` всегда диктуется сайдбаром. Если задашь вопрос, не переключив — агент ответит про того, кто выделен. Работает и для детей, и для супруги.

**Голос.** Если браузер поддерживает Web Speech API и язык — русский (интерфейс RU по умолчанию), кнопка микрофона надиктовывает текст в поле чата. Серверного ASR нет, всё в браузере.

**Советы.**
- Явно проси формат: `«выведи табличкой»`, `«дай график»`, `«summary в трёх пунктах»`.
- Комбинируй: `«разбери входящие и обнови диагнозы, потом собери отчёт»` — агент сделает всё в одном ходу.
- Виджет получился не тот — просто скажи: `«перерисуй график только за 2026»`.
- Переименовал/перенёс папку члена — обнови страницу; `family.json` — источник правды для сайдбара.

## Быстрый старт

Требования: Node.js 20+, tmux, [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) с пройденным OAuth (`claude` в `$PATH`), pm2 опционально для prod.

```bash
git clone git@github.com:dailysergey/family-health.git && cd family-health

cp web/.env.example web/.env.local
# отредактируй: HEALTH_DATA_DIR, HEALTH_PIN, HEALTH_INGEST_SECRET
(cd web && npm install && npm run build)
(cd mcp && npm install)

cp -r data.example data
# HEALTH_INGEST_SECRET в web/.env.local должен совпадать с data/.mcp.json

bash runtime/start-claude.sh       # tmux new-session -d -s health "claude ..."
cd web && PORT=3100 npm start      # или: pm2 start ecosystem.config.js
```

Открой <http://localhost:3100>, введи PIN из `web/.env.local`.

### Переменные окружения (`web/.env.local`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HEALTH_DATA_DIR` | — | абсолютный путь к папке с данными семьи |
| `HEALTH_TMUX_SESSION` | `health` | имя tmux-сессии с Claude |
| `HEALTH_INGEST_SECRET` | — | секрет для `/api/ingest` (должен совпадать с `data/.mcp.json`) |
| `HEALTH_PIN` | — | PIN для входа в веб |
| `HEALTH_START_SCRIPT` | `./runtime/start-claude.sh` | скрипт запуска tmux-сессии |

## Безопасность

Claude запускается с `--dangerously-skip-permissions`, чтобы автономно читать файлы, двигать документы между папками и вызывать MCP-инструменты без подтверждений. Запускай только на своей машине, не выставляй tmux-сокет в сеть; если публикуешь `PORT=3100` — ставь перед ним нормальную авторизацию (basic-auth / OIDC). PIN — минимальный барьер, не замена нормальной авторизации.

Ничто из этого не заменяет врача — ассистент помогает разобраться в анализах, но не ставит диагнозы.
